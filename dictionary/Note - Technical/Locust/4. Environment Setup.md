
# Performance Test Environment Setup Guide  
  
This document provides step-by-step instructions to set up the performance testing environment for the E-commerce API, as referenced in `[performance_test_plan.md](http://performance_test_plan.md/)`.

## 2. Detailed Configuration and Installation  
  
### 2.1. Load Generator  
  
-   **Purpose:** Run Locust to generate high traffic to the Application Server.  
-   **Recommended Configuration:**  
    -   **OS:** Ubuntu 22.04 LTS  
    -   **CPU:** 4 Cores  
    -   **RAM:** 8 GB  
-   **Installation Steps:**  
  
    1.  **Update system and install Python:**  
        ```bash  
        sudo apt-get update  
        sudo apt-get install -y python3-pip python3.10-venv  
        ```  
  
    2.  **Create virtual environment and install Locust:**  
        ```bash  
        python3 -m venv locust-env  
        source locust-env/bin/activate  
        pip install locust  
        ```  
  
    3.  **Copy Locust script:**  
        -   Copy the `locustfile.py` to this machine.  
  
    4.  **Configure Firewall:**  
        -   Open port `8089` for Locust web UI access.  
        ```bash  
        sudo ufw allow 8089/tcp  
        sudo ufw allow ssh  
        sudo ufw enable  
        ```  
  
### 2.2. Application Server  
  
-   **Purpose:** Run the E-commerce API application.  
-   **Recommended Configuration:**  
    -   **OS:** Ubuntu 22.04 LTS  
    -   **CPU:** 4 Cores  
    -   **RAM:** 8 GB  
-   **Installation Steps:**  
  
    1.  **Install dependencies and application code:**  
        -   Install Python, Git, and application dependencies.  
        -   Clone your source code and install dependencies from `requirements.txt`.  
  
    2.  **Install Gunicorn (WSGI Server):**  
        ```bash  
        pip install gunicorn  
        ```  
        -   **Run command (example):**  
        ```bash  
        gunicorn --workers 4 --bind 0.0.0.0:5000 your_project.wsgi:application  
        ```  
  
    3.  **Install Node Exporter for monitoring:**  
        ```bash  
        wget [https://github.com/prometheus/node_exporter/releases/download/v1.7.0/node_exporter-1.7.0.linux-amd64.tar.gz](https://github.com/prometheus/node_exporter/releases/download/v1.7.0/node_exporter-1.7.0.linux-amd64.tar.gz)  
        tar xvfz node_exporter-1.7.0.linux-amd64.tar.gz  
        sudo mv node_exporter-1.7.0.linux-amd64/node_exporter /usr/local/bin/  
        ```  
  
    4.  **Configure Firewall:**  
        -   Open port `5000` (or your app's port) and port `9100` for Node Exporter.  
        ```bash  
        sudo ufw allow 5000/tcp  
        sudo ufw allow 9100/tcp  
        sudo ufw allow ssh  
        sudo ufw enable  
        ```  
  
### 2.3. Database Server  
  
-   **Purpose:** Store application data.  
-   **Recommended Configuration:**  
    -   **OS:** Ubuntu 22.04 LTS  
    -   **CPU:** 2 Cores  
    -   **RAM:** 4 GB (increase if data is large)  
-   **Installation Steps:**  
  
    1.  **Install PostgreSQL (example):**  
        ```bash  
        sudo apt-get update  
        sudo apt-get install -y postgresql postgresql-contrib  
        ```  
  
    2.  **Optimize configuration:**  
        -   Modify `postgresql.conf` to increase `max_connections`, `shared_buffers`, etc.  
  
    3.  **Prepare data:**  
        -   Write a Python script (using `psycopg2` or `SQLAlchemy`) to create sample data.  
        -   **Create Snapshot (Backup):**  
        ```bash  
        pg_dump -U your_user -d your_db -F c -b -v -f initial_data.dump  
        ```  
        -   **Restore Snapshot:**  
        ```bash  
        pg_restore -U your_user -d your_db -v --clean --no-acl --no-owner initial_data.dump  
        ```  
  
    4.  **Configure Firewall:**  
        -   Only allow connection from Application Server to port `5432`.  
        ```bash  
        sudo ufw allow from <APP_SERVER_IP> to any port 5432 proto tcp  
        sudo ufw allow ssh  
        sudo ufw enable  
        ```  
  
## 3. Readiness Checklist  
  
Before starting the test, ensure:  
- [ ] All servers are installed and configured properly.  
- [ ] Network connectivity between servers is verified (Load Gen -> App, App -> DB).  
- [ ] Necessary ports are opened in the firewall.  
- [ ] Test data is created and backed up.  
- [ ] `locustfile.py` is placed on the Load Generator.  
- [ ] Monitoring tools (Prometheus/Grafana) are set up to collect metrics from servers.
