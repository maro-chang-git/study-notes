The most popular request library in Python is `request`. However, locust has it built-in request library, which is more lightweight, and support performance testing better. 

https://requests.readthedocs.io/

```python
from locust import HttpUser, task

class HelloWorldUser(HttpUser):
    @task
    def hello_world(self):
        self.client.get("/hello")
        self.client.get("/world")
```
