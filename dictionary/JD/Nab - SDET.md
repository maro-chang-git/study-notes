Nab - SDET
### Responsibilities:
- Develop, maintain, and enhance applications using Python
- Build Python-based automation solutions to improve operational efficiency
- Design, write, and optimize SQL queries for data analysis and manipulation
- Use Postman to test, debug, and validate APIs
- Build, deploy and manage application and services on AWS
- Troubleshoot, debug, and resolve issues related to cloud infrastructure and databases
- Collaborate with other teams to develop and deploy cloud-based solutions
- Continuesly explore and adopt new technologies to improve system performance
- ability to clear Codility assessment in Python

### Requirements:
- 4-6 years of experience in Python development
- Strong Python programming skills with clean coding practices
- Solid experience with SQL query design and optimization
- Hands-on experience with Postman and REST APIs
- Working experience with AWS cloud services
- Good analytical, debugging and problem-solving skills
- Good at English communication skill. 

-----------------------------
Despite the "SDET" title, this role leans more toward a Python Developer / Automation Engineer than a traditional SDET.
It blends **backend development, automation, cloud ops, and API work** — with testing being just one component.

### Core Skills
- Python
- SQL: design + optimise + write. 
    Expect questions on **indexing, indexing strategy, query plans, joins, and performance tuning.**
    Redshift: Query Plan visualizer, Workload Management (WLM)

- Rest APIs + Postman: Automated API test suites +  Newman
- AWS: "Build, deploy, and manage" -> hands-on infra work. Key services to focus on: EC2, S3, Lambda, RDS, IAM, and Cloud Watch.
