### Run 1st locust
1. Write `locustfile.py`
```python
   from locust import HttpUser, task

class HelloWorldUser(HttpUser):
    @task
    def hello_world(self):
        self.client.get("/hello")
        self.client.get("/world")
   ```

2. Run locust server
   
 ```bash
#run locust - no host defined
locust

#run locust - with host is defined
locust --host=[http://example.com](http://example.com/)

#run locut - with different file name
locust -f /locust_file/my_locust_file.py --host=http://example.com 
   ```
