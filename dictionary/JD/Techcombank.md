# Middle/Senior Data Tester
## Key Accountabilities
### Test Planning
- Analyze data requirements, workflows, and processes to define comprehensive testing scope.
- Create detailed test plans, test cases, and test data.
- Write SQL queries to validate data quality, logic, and integrity.
- Control tasks and timelines, proactively report issues.

### Test Execution
- Perform testing of data migrations, transformations, and integrations to ensure accuracy and consistency.
- Validate datasets, reports, and dashboards against business rules.
- Execute manual and automated tests for databases.
- Test large datasets for accuracy, completeness, and consistency across platforms (SQL, NoSQL).
- Conduct Regression Testing on updated and existing ETL processes.
- Collaborate with data engineers, business analysts, and test teams to understand data models and requirements.
- Support troubleshooting and resolution of data-related issues.

### Defect Management
- Identify, document, and track data quality issues using tools like JIRA.
- Work with relevant teams to resolve defects.
- Prepare and deliver progress reports for squad and tribe leads.

### Automation
- Develop automated test scripts using Python, SQL, or other data testing frameworks to reduce manual effort.

### Tech Stack & Tools
- Databases: MySQL, PostgreSQL, SQL Server, Oracle.
- ETL & Data: ETL processes, Data Warehouse, Big Data.
- Tools: JIRA, TestLink, Trello, TestRail.
- Programming: Python (preferred).
- Cloud Platforms (Nice to have): AWS, Azure, GCP.
- Certifications (Nice to have): ISTQB Foundation/Advanced.

2–5 years of experience in software development projects.
Minimum 1 year in data testing.
Strong SQL skills and experience with large datasets.
Good analytical, communication, and teamwork skills.
